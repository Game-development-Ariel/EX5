# הקונפיגורציה החיה (Live Ops)

המשחק מוריד את הקובץ [live-config.json](live-config.json) מהענף `main` בתחילת כל הרצה. מה שכתוב בו משנה את המשחק בלי לבנות גרסה חדשה: משנים את הקובץ כאן ב-GitHub, ובהרצה הבאה המשחק כבר מתנהג אחרת. אם אין רשת או שהקובץ שבור, המשחק רץ כרגיל עם המספרים שבקוד.

## מספרי הקושי

לכל רמה (`easy`, `medium`, `hard`) אפשר לדרוס שלושה מספרים. `-1` אומר "להשאיר את המספר שבקוד".

| שדה | מה הוא משנה |
|---|---|
| `startingHope` | התקווה שהגיבור מתחיל איתה |
| `hopeLostWhenCaught` | כמה תקווה יורדת בכל היתפסות |
| `hopeNaturalDecayPerMinute` | כמה תקווה יורדת מעצמה בכל דקה. בקוד 0 בכל הרמות, כי לפי המסמך התקווה לא יורדת עם הזמן. אפשר להדליק אותה כאן לבדיקה |

## האירוע החי: הפסקת חשמל

כש-`enabled` הוא `true` והשעה (UTC) בין `startUtc` ל-`endUtc`, החשמל במנהרה נופל: הנורות כבויות, המצלמות לא רואות, המנהרה חשוכה יותר והשומר מסייר מהר יותר.

| שדה | מה הוא משנה |
|---|---|
| `enabled` | מפעיל או מכבה את האירוע |
| `startUtc`, `endUtc` | מתי האירוע מתחיל ונגמר, לפי שעון UTC |
| `openingLine` | השורה שמופיעה מתחת ל-"Day 1" בפתיחה |
| `tunnelLightFactor` | כמה אור נשאר במנהרה. 1 = רגיל, 0.45 = פחות מחצי |
| `guardSpeedFactor` | כמה מהר השומר הולך. 1 = רגיל, 1.3 = מהר ב-30 אחוז |

## האירוע דלוק עכשיו

בקובץ שב-`main` האירוע דלוק (`"enabled": true`) מ-23.11.2026 עד 31.12.2026. מי שמשחק בתקופה הזאת, בדפדפן או ב-Unity, רואה את הפסקת החשמל.

## מה הבודק יראה

1. **בפתיחה**, מתחת ל-"Day 1", מופיעה השורה: "The lights are out. Their eyes are blind today."
2. **הנורות כבויות**, והמנהרה חשוכה יותר (45 אחוז מהאור הרגיל).
3. **המצלמות כבויות:** בלי קונוס אור, בלי נורה אדומה ובלי זמזום. הן לא רואות, ואי אפשר להיתפס בהן. גם הדופק לא עולה לידן.
4. **השומר מהיר יותר**, ב-30 אחוז. עכשיו הוא הסכנה היחידה.
5. **מקש F3** פותח דף בדיקה. בדף כתוב `live config: from the file, version 1   power outage: True`.

**איך רואים את המשחק בלי האירוע:** המשחק מוריד את הקובץ בכל פעם שהשלב נטען. משחקים עד מסך הסיום, מנתקים את האינטרנט ולוחצים Play again. השלב נטען מחדש, אחרי חמש שניות המשחק מוותר על הקובץ, וממשיך עם המספרים שבקוד.

## איך מפעילים ומכבים את האירוע

1. פותחים את `live-config.json` ב-GitHub ולוחצים על העיפרון (Edit).
2. משנים את `"enabled"` (`true` דולק, `false` כבוי), או את התאריכים `startUtc` ו-`endUtc`.
3. שומרים (Commit) לענף `main`.
4. מפעילים את המשחק מחדש. GitHub מעדכן את הקובץ אצלו תוך חמש דקות לכל היותר.
